# Medium OPML Exporter 🚀

**Liberate your Medium follows.**  
Export your Following list to an OPML file and reclaim your content feed — in any RSS reader you like. No more Medium walls, no more algorithmic noise. 📡⚔️

## Features ✨

- 📝 Export your Medium Following list to **standard OPML format**
- 🔁 Compatible with Feedly, Inoreader, NetNewsWire, and more
- ⚡ Lightweight, fast, no dependencies
- 🧠 Built for users who want **control** over their information diet

## Installation 📦

1. Install a userscript manager:
   - [Tampermonkey](https://www.tampermonkey.net/)
   - [Greasemonkey](https://www.greasespot.net/)
2. Download this script: [medium-opml-exporter.user.js](./medium-opml-exporter.user.js)
3. Open your Medium Following page and let the script do the work

## Usage 🛠️

1. Go to your [Medium Following page](https://medium.com/me/following)
2. Click **Export to OPML** (button injected by the script)
3. Save the file
4. Import it into your favorite RSS reader

## Why this exists ❓

Medium offers no native RSS export for your follows.  
This script fills that gap — because **your attention shouldn't be trapped**.
